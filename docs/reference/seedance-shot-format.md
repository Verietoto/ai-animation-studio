# Format Prompt Shot Seedance 2.0 (dari user, plan 18 Revisi 4)

Dua bagian: **blok global** (sekali) dan **daftar shot**.

| Label | Isi |
|---|---|
| FORMAT | `15s / 10 SHOTS / genre` |
| SUBJECT | referensi gambar `@image_1 @image_2`, lalu usia, rambut, kulit, mata, aksesori, sifat |
| WARDROBE | pakaian detail dari atas sampai sepatu |
| ENVIRONMENT | lokasi utama + lokasi kecil berlabel (A), (B), (C) |
| MOOD | nuansa dan arahan emosi |

Tiap shot: `SHOT N — mulai to selesai, UKURAN, LENSA, GERAK. Aksi.` Contoh:
`SHOT 4 — 0:04 to 0:06, MS, 35mm, slow push-in. She opens the heavy study door...`

- Ukuran: WS, MS, MCU, CU, ECU. Lensa: 24/35/50/85mm.
- Gerak: locked, slow push-in, pull-out, tracking, pan, tilt.
- Timestamp berurutan tanpa tumpang tindih; total = durasi di FORMAT; shot 1-3 dtk.
- Variasikan ukuran dan lensa. Satu shot satu ide aksi. Aksi per momen, bukan ringkasan.
- Konsistensi (pakaian, aksesori) cukup di blok global. Gunakan `@image_N` di SUBJECT.
