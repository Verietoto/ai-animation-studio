# Docs

Setiap fitur melalui tiga tahap, ditulis di tiga folder:

- `plan/` untuk perencanaan
- `grill/` untuk mencari lubang, risiko, dan bug
- `implementation/` untuk catatan implementasi

Penamaan: `NN-judul-kebab-case.md` (contoh `01-architecture-plan.md`), nomor sama untuk satu fitur di ketiga folder. Template ada di `_templates/`. Aturan lengkap ada di `CLAUDE.md`.
